# 四级单词 · 无痛背单词

> ### 在线使用（打开链接即可开始背单词，无需安装任何东西）
> ## https://ZiChen-hub.github.io/LearnEnglish/

一个**纯前端、零依赖、打开即用**的大学英语四级背单词工具。用记忆卡片 + 艾宾浩斯记忆周期把"背单词"拆成轻松的每日小任务：点一下翻卡看释义，听一遍发音，选一次"记住了 / 有点印象 / 不认识"，系统自动安排下次复习时间。

面向备考四级的同学，界面简约清爽，**无广告、无弹窗、无注册、无后端**，所有学习数据都存在你自己的浏览器里。

## 一、功能一览

| 模块 | 说明 |
| --- | --- |
| 四级单词词库 | 4536 条大学英语四级大纲词汇，支持单词 / 中文释义双向检索 |
| 记忆卡片 | 卡片 3D 翻转动画，点击（或按空格 / 回车）翻面查看释义 |

| 音标 + 释义 + 真题例句 | 国际音标、中文释义、四级真题原句（标注年份 / 卷次 / 题型） |
| 艾宾浩斯复习规划 | 8 级记忆周期：5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 |
| 收藏生词本 | 一键收藏难词、批量朗读、一键清空 |
| 深色 / 浅色模式 | 跟随系统偏好，也可手动切换，选择会被记住 |
| 学习进度统计 | 已学 / 已掌握环形成长图、近 7 天学习量柱状图、连续学习天数、阶段分布 |
| 进度本地保存 | 全部数据存在 `localStorage`，刷新、关页、重开都不丢进度 |

### 页面结构（5 个标签页）

- **学习**：每次一组 20 个新词，卡片记忆，三档评价。
- **复习**：显示今日待复习数量、未来 7 天复习安排、记忆阶段分布。
- **词库**：4536 词全库检索，行内朗读与收藏。
- **生词本**：收藏单词集中管理。
- **进度**：学习统计面板。

### 操作方式

- **翻卡**：点击卡片任意处，或键盘 `Tab` 聚焦卡片后按 `空格` / `回车`。
- **发音**：点卡片右上角的喇叭按钮，或词库 / 生词本行内的喇叭。
- **评价**：卡片下方三个按钮——
  - `记住了`：进入下一个记忆周期（走完 15 天即视为**已掌握**）；
  - `有点印象`：记忆阶段不变，间隔缩短到一半再复习；
  - `不认识`：回到第 1 级（5 分钟后重新记忆）。
- **收藏**：卡片下方「收藏」按钮，或列表行内的星标。
- **切换主题**：右上角太阳 / 月亮按钮。

> 设计目标就是"把压力降到最低"：一次只面对一张卡，只做一个判断，没有多余弹窗和打扰。

## 二、词汇来源（重要）

词库**严格取自大学英语四级大纲词汇**，由两份国内权威教育机构开源的公开数据合并、清洗而成：

| 数据 | 内容 | 开源地址 | 原始出处 |
| --- | --- | --- | --- |
| 大学英语四级大纲词汇表 | 词头、国际音标、中文释义 | <https://github.com/mahavivo/english-wordlists>（`CET4_edited.txt`） | 《全国大学英语四、六级考试大纲（2016 年版）》四级词表，Google 关键词：全国大学英语四六级考试委员会 大纲词表 |
| 有道考神 · 四级词库 | 美/英音标、释义、**四级真题例句**（含年份 / 卷次 / 题型） | <https://github.com/kajweb/dict>（`book/CET4_1.zip`、`book/CET4_2.zip`、`book/CET4_3.zip`、`book/Level4_2.zip`） | 网易有道背单词 App 公开词库（有道考神四级词汇） |

### 词库清洗与校验流程

构建脚本 `tools/build_wordbook.py` 会自动下载上述数据源并完成清洗，规则包括：

1. **只保留大纲词**：以大纲词表为唯一主表，逐词比对，剔除超纲词——最终 4536 条，全部属于四级大纲范围。
2. **释义以大纲为准**：中文释义直接采用大纲词表释义，避免词典释义互相覆盖或出现错误释义；音标缺失时用有道词库补齐。
3. **剔除缩写与无效条目**：过滤 `a.m.`、`B.C.`、`i.e.`、`P.M.` 等非单词条目以及释义为空 / 过短的异常记录。
4. **规范化词头**：统一撇号（`oˈclock` → `o'clock`），去除 `systematic(al)`、`toward(s)` 这类可选后缀标注。
5. **字符清洗**：去掉 HTML 标签、零宽字符、PDF 转换残留的私用区字符，并把有道数据中混入的法语字母（é / ê / ç 等）转写为 ASCII。
6. **真题例句校验**：真题例句必须真实出现该词（含词形变化），去除省略号碎片、过短（<12 字符）与过长（>180 字符）句子，最多保留 2 条；例句统一句首大写、去重。
7. **出处年份纠错**：源数据存在年份笔误（如 `2107.12`），统一归位为合理年份（`2017.12`）。
8. **去重**：重复词头只保留一条。

## 三、项目结构

```
LearnEnglish/
├── index.html              # 单页应用（HTML + CSS + 原生 JS，零依赖）
├── data/
│   ├── words.json          # 四级词库（4536 词，唯一数据源，供页面与其它程序读取）
│   └── words.js            # 同一份数据的 JS 包装，用于 file:// 直接打开时离线加载
├── tools/
│   └── build_wordbook.py   # 词库下载 / 清洗 / 校验 / 生成脚本
├── .nojekyll               # 空文件，关闭 GitHub Pages 的 Jekyll 处理，避免静态资源异常
└── README.md               # 本文档
```

**为什么同时提供 `words.json` 与 `words.js`？**
`words.json` 是标准词库文件；浏览器以 `file://` 方式直接打开网页时会拦截本地 `fetch` 请求，因此额外生成一份同样数据的 `words.js`（`window.CET4_WORDBOOK`）作为离线兜底。页面优先使用 `words.js`，在 GitHub Pages 等可通过网络访问的场景也可直接读取 `words.json`。

### 方式一：在线使用（推荐，打开链接就能用）

直接访问：

### **<https://ZiChen-hub.github.io/LearnEnglish/>**

无需下载、无需安装、无需注册，打开即可开始背单词，手机浏览器同样支持。学习进度保存在当前浏览器的 `localStorage` 中。

下载 / 克隆本项目后，**双击 `index.html`** 即可开始背单词，无需安装任何东西、无需启动服务。

### 方式三：本地运行（体验与线上完全一致）

在项目根目录执行任意一条命令，然后访问 <http://localhost:8000>：

```bash
# Python 3
python3 -m http.server 8000

# 或者 Node.js
npx http-server -p 8000
```

打开 <http://localhost:8000/index.html> 即可使用。

### 方式四：重新生成词库（可选）

需要联网，会自动从上述两个开源仓库拉取原始数据：

```bash
python3 tools/build_wordbook.py
```

脚本会输出 `data/words.json` 与 `data/words.js`，并在终端打印清洗统计数据。

## 五、GitHub Pages 部署指引

### 当前状态：已开启并在线 ✅

本仓库的 GitHub Pages **已开启、构建成功**，打开链接即可直接使用：

### **在线地址：<https://ZiChen-hub.github.io/LearnEnglish/>**

站点内容就是仓库根目录（`index.html` + `data/` + `.nojekyll`）。发布源当前为 `gh-pages` 分支根目录，而该分支的内容与 `main` 分支根目录**完全一致（同一个提交）**，所以线上展示的页面与"发布 `main` 分支根目录"完全相同，效果没有差别。

> 更新线上内容：当前发布源为 `gh-pages`，推送 `main` 后需同步到 `gh-pages`（`git push origin main:gh-pages`）才会刷新线上页面；若已切回 `main` 发布源，则推送 `main` 后约 1 分钟自动更新。

### 本项目开启 Pages 的完整步骤（供参考 / 复刻）

1. 把本项目推送到 GitHub 仓库（例如 `https://github.com/<你的用户名>/LearnEnglish`）：

   ```bash
   git init
   git add .
   git commit -m "feat: 四级单词无痛背单词工具（词库+记忆卡片+艾宾浩斯复习）"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/LearnEnglish.git
   git push -u origin main
   ```

2. 在项目根目录放一个空的 `.nojekyll` 文件（本项目已包含）——GitHub Pages 默认会用 Jekyll 处理站点，遇到以下划线开头的目录或特殊文件时可能报错 / 漏掉静态资源，`.nojekyll` 可关闭该处理，确保 `data/words.json`、`data/words.js` 等资源被原样发布：

   ```bash
   touch .nojekyll
   git add .nojekyll && git commit -m "chore: 添加 .nojekyll 关闭 Jekyll" && git push
   ```

3. 打开仓库页面 → **Settings** → 左侧 **Pages**。

4. 在 **Build and deployment** → **Source** 选择 `Deploy from a branch`；
   **Branch** 选择 `main`，目录选择 **`/ (root)`**，点击 **Save**。

5. 等待 1~2 分钟，页面顶部会出现站点地址，形如：

   ```
   https://<你的用户名>.github.io/LearnEnglish/
   ```

   也可以用命令行开启 / 修改发布源（需已登录 `gh`，且令牌具备仓库 Pages 写权限）：

   ```bash
   # 首次开启（仓库尚未启用 Pages）
   gh api -X POST repos/<你的用户名>/LearnEnglish/pages \
     -f 'source[branch]=main' -f 'source[path]=/'

   # 已启用、只想把发布源改成 main 分支根目录
   gh api -X PUT repos/<你的用户名>/LearnEnglish/pages \
     -f 'source[branch]=main' -f 'source[path]=/'
   ```

6. 打开站点即可使用。因为全部是静态文件、数据保存在 `localStorage`，Pages 上无需任何额外配置。手机浏览器访问同一地址即可继续学习（**注意：不同设备 / 浏览器的学习进度相互独立**）。

> 如果页面显示 404，请确认：
> - `Settings → Pages` 的分支与目录选对（`main` + `/ (root)`）；
> - `index.html` 位于仓库根目录；
> - 仓库为 Public（免费账号的 Pages 仅支持公开仓库）；
> - 刚开启时首次构建需要 1~2 分钟，稍等后刷新即可。

## 六、常见问题

**Q：刷新页面学习进度会丢吗？**
不会。进度、生词本、统计、主题都保存在浏览器 `localStorage`（键名前缀 `cet4.`），除非手动清空浏览器数据或点击「重置全部学习进度」。

**Q：换手机 / 换浏览器进度能同步吗？**
不能。本项目刻意不做后端，数据只在本机。这也是它"打开就能用、无需注册"的原因。

**Q：为什么有的单词没有真题例句？**
有道的四级词库只对部分词条标注了真题原句。为了保证"不编造、不冒充"，没有真题例句的词条只展示词典例句，并明确标注为「词典例句」。

**Q：没有声音？**
发音使用浏览器原生语音合成。若无声，请检查系统是否安装了英文语音包（Windows：设置 → 时间和语言 → 语音；macOS / iOS / Android 一般自带），或换用 Chrome / Edge / Safari 试试。

**Q：点击卡片没反应？**
卡片是整块可点击区域，若点击的是右上角喇叭按钮，会触发朗读而非翻卡。

## 七、技术说明

- 纯前端实现：`index.html` 内联 CSS 与原生 JavaScript（ES5 语法，兼容性好），**无框架、无构建、无 CDN 依赖**。
- 主题通过 `data-theme` 属性 + CSS 变量切换；默认跟随系统 `prefers-color-scheme`。
- 响应式：`721px` 断点，桌面端为顶部标签导航，移动端为底部标签栏；已适配安全区 `env(safe-area-inset-bottom)`。
- 无障碍：卡片支持键盘操作，按钮带 `aria-label`，导航使用 `aria-current`，并适配 `prefers-reduced-motion`。
- 数据体积：词库约 1.3 MB，首屏一次性载入，本地无网络请求。
